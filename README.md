# Masoya Landing Page

A production-ready static landing page for the Masoya dating app.

## Structure

```text
masoya-landing/
├── index.html
├── README.md
└── assets/
    ├── logo.svg
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── main.js
    └── images/
        └── (reserved for future photos/screenshots)
```

## Deploy to GitHub Pages

1. Create or open the repository used by `https://masoyaapp.github.io/`.
2. Copy the files in this folder into the repository root.
3. Commit and push to GitHub.
4. Enable GitHub Pages from the repository's Pages settings if it is not already enabled.

## Replace branding / visuals

- Replace `assets/logo.svg` with the final Masoya logo while keeping the same filename.
- Add app screenshots to `assets/images/` and update the `<img>` elements in `index.html` when you have the final screenshots.
- The current hero and app preview are CSS-built, so the site works without image assets.
